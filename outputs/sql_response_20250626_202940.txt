Here is the BigQuery SQL query that answers the question:

```sql
SELECT c.customer_id, c.company_name, c.contact_name
FROM customers c
JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_date BETWEEN '1998-01-01' AND '1998-12-31'
ORDER BY c.company_name;
```

This query joins the `customers` table with the `orders` table on the `customer_id` column, and then filters the results to only include customers who placed an order in 1998. The `ORDER BY` clause is used to sort the results by company name.
