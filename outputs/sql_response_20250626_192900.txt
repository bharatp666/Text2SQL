Here is the SQL query that lists all customers who placed an order in 1998:
```
SELECT c.customer_id, c.company_name, c.contact_name
FROM customers c
JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_date >= DATE('1998-01-01') AND o.order_date < DATE('1999-01-01');
```
This query joins the `customers` table with the `orders` table on the `customer_id` column, and then filters the results to only include orders with an `order_date` in 1998. The `DATE` function is used to create a date range for the filter.
